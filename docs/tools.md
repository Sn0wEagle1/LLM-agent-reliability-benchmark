# Инструменты

Описание и параметры выгружены из исполняемого кода.

## search_tickets

Поиск заявок по фильтрам. Результаты выдаются постранично (по 5 записей).

Обязательные параметры: нет.

Изменение данных: нет.

## get_ticket

Получить полные сведения о заявке по идентификатору.

Обязательные параметры: ticket_id.

Изменение данных: нет.

## get_ticket_history

Получить журнал изменений заявки по идентификатору.

Обязательные параметры: ticket_id.

Изменение данных: нет.

## create_ticket

Создать новую заявку. Исполнитель назначается отдельной операцией assign_ticket.

Обязательные параметры: description, priority, category.

Изменение данных: да.

## update_ticket

Обновить поля заявки по идентификатору (описание, приоритет, категорию, срок, трудозатраты).

Обязательные параметры: ticket_id.

Изменение данных: да.

## assign_ticket

Назначить исполнителя заявки.

Обязательные параметры: ticket_id, assignee.

Изменение данных: да.

## change_status

Изменить статус заявки.

Обязательные параметры: ticket_id, new_status.

Изменение данных: да.

## add_comment

Добавить комментарий к заявке.

Обязательные параметры: ticket_id, text.

Изменение данных: да.

## check_status_transition

Детерминированная проверка по регламенту: разрешён ли перевод заявки в указанный статус.

Обязательные параметры: ticket_id, new_status.

Изменение данных: нет.
